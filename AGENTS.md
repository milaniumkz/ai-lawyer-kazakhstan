- Всегда применять `limit-efficient-quality`.
- Работать вертикальными срезами: contract → backend → AI/stub → mobile/admin → tests → docs → commit.

- Не реализовывать фиктивные production-интеграции с государственными сервисами.
- Использовать Flutter SDK: `/Volumes/PD1000/job/flutter/bin/flutter`.
- Перед завершением среза запускать `npm run check` и, если Docker доступен, `npm run docker:config`.
