# AI-Юрист Казахстан

Монорепозиторий release-кандидата «AI-Юрист Казахстан».

## Структура

- `apps/mobile` — Flutter Android/iOS приложение.
- `apps/admin` — Next.js admin panel.
- `services/api` — NestJS core API и integration gateway.
- `services/ai` — FastAPI AI/RAG orchestration service.
- `packages/contracts` — OpenAPI и общие контракты.
- `infra` — локальная инфраструктура.
- `docs` — требования, статусы, ADR, release-документы.

## Дизайн

Источник визуальной истины: `дизайн/темная` и `дизайн/светлая `.
Default theme: светлая premium Kazakhstan theme. Темная тема поддерживается системной настройкой.

Проект создан из пустого репозитория. См. `docs/project/IMPLEMENTATION_STATUS.md` и `docs/project/CODEX_HANDOFF.md`.
