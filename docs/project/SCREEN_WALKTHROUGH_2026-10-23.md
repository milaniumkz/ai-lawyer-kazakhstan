## Исправленные дефекты

- Пункты веб-профиля больше не сохраняют старые данные вместо открытия редактирования и не сообщают «раздел открыт» без действия. Добавлены настоящие поля и загрузка профиля. Новый `PATCH /profiles/{profileId}` сохраняет запись без дубликата и проверяет владельца; пустое поле ИИН не стирает сохранённый хеш.
- Успешное сохранение профиля теперь видно в самой форме; при ошибке загрузки есть повтор, а поля не затираются автоматическим сохранением.
- В профиле доступны переходы к помощи, подписке, календарю и нормам права.
- Кнопки скачивания вложенного PDF на экране отправки подключены в вебе и Flutter; запись ручного статуса не названа фактической отправкой.
- Веб-вход по e-mail подключён к существующему OTP API. Повторный запрос кода вызывает API в обеих версиях, статический таймер и фиктивный успех убраны. Повторная отправка/проверка блокируется на время запроса.
- Поиск помощи не перезаписывает описание дела. Убраны старые CSS-правила, скрывавшие форму поддержки, экспорт/удаление/сохранение настроек, действие подготовки претензии и добавление нормы в документ. Результат поиска и сообщения проверки цитат больше не скрываются.
- Неподключённые голосовые ответы и обезличивание не показывают включённую защиту. Во Flutter устранены демонстрационное имя ИП, ложные проценты и статус готовности до выполнения работы; в карточке тарифа без данных нет активного Free/TTS по умолчанию.
- Устранены переполнения приветствия, помощи и экрана отправки при крупном тексте. Заголовки используют включённый в приложение шрифт с кириллицей.
- Flutter рассчитывает высоту длинного поля из `View.viewInsets`: `Scaffold` потребляет `MediaQuery.viewInsets` внутри изменённой области. Проверка на маленьком экране с 20 строками и масштабом 200% воспроизвела переполнение и подтверждает исправление. Стрелка и действие клавиатуры Send проверяются отдельно.
- Веб закрепляет поле сразу при фокусе на мобильной ширине, не ожидая задержанного события изменения viewport iOS. Проверка включает длинную страницу и прокрутку; Enter/стрелка отправляют один раз, Shift+Enter сохраняет перенос. Это эмуляция viewport, не физический Safari.
- Во Flutter подключены русские системные локализации для меню редактирования, календаря и стандартных элементов.
- При юридическом поиске второй проход больше не заменяет уже проверенные материальные нормы только процессуальными статьями. Неподтверждённая редакция по-прежнему требует проверки, это предупреждение не отключалось.
- Обновлены уязвимые зависимости Next.js/Fastify и согласованы версии NestJS. Аудит зависимостей после обновления: 0 известных уязвимостей. Это не заменяет отдельное завершение аудита авторизации и защиты данных.
