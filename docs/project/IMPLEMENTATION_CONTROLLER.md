# Implementation Controller

Работа идет вертикальными срезами: contract -> backend -> AI/local adapter -> web/mobile UI -> tests -> docs -> commit.

Текущий gate: auth не переписывать без дефекта; основной активный срез - определение категории спора.

Перед следующим этапом нельзя переходить к документам/искам, пока classification API, сохранение, уточнения, подтверждение и ручная смена категории не пройдут проверки.
