# Acceptance Criteria

- Mobile launches and covers the main 25-screen navigation in light and dark themes.
- Auth/profile/case/document/RAG flows work in local mode with explicit external blockers.
- Legal answers use confirmed official KZ citations or safe refusal.
- High-risk, low-confidence and no-source results go to human review.
- API, admin, AI service and mobile pass lint/typecheck/test/build gates where toolchain is available.
- No Russian legal entities, norms, courts, rubles, INN/OGRN or РФ references in product behavior.
- No production release claim without Android/iOS RC builds, security checks and closed release checklist.
