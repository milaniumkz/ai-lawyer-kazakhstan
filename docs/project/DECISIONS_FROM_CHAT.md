# Decisions From Chat

- Auth-first flow обязателен: телефон -> OTP -> профиль при первом входе -> главная.
- SMS-код в RC показывается на экране как local adapter поведение.
- Нижняя навигация не показывается на auth/register/OTP.
- Данные должны идти из API/БД; демо-данные не выдаются за реальные.
- Категория спора определяется до генерации документов.
- Все legal behavior ограничено Казахстаном.
