Последние 11 PNG из четырёх архивов AIZAN имеют приоритет над прежними 25 экранами. Пользователь выбрал веб и Flutter.

## Что изменено

Веб и Flutter используют чёрно-золотую палитру, AIZAN, красный микрофон, общий заголовок и нижнюю навигацию с камерой. Фрагменты PNG используются только как декоративные иллюстрации; поля, текст и кнопки остаются настоящими элементами интерфейса. Обновлены главная, вход, список дел, голосовой ввод, категория, документы, добавление документа, анализ и подготовка/просмотр/отправка претензии. Новый маршрут Flutter: `/documents/add`.

Введённый текст сохраняется при переключении к голосу; отдельная кнопка нового дела очищает черновик. Запись и пауза используют доступные API устройства. В Flutter камера подключена через image_picker, PDF через pdf/printing; зависимости ещё не разрешены и не проверены SDK. Веб экспортирует документ через окно печати браузера. Ручная фиксация отправки требует подтверждения и не считается реальной доставкой.

Фиксированные 82% и фиктивное завершение анализа убраны. Существующий backend выдаёт stub:// upload session и сохраняет метаданные; настоящее файловое хранилище и автоматический OCR остаются неподключёнными. Интерфейс сообщает об этом. Каталог готовых шаблонов для вкладки документов также требует подключения.

Flutter SDK отсутствует. Репозиторий SDK скачан в `/workspace/flutter-sdk`, но Dart SDK с storage.googleapis.com блокируется прокси (CONNECT 403). Домен добавлен в черновик сетевых настроек облачной среды; изменение требует применения в настройках среды. npm run check останавливается на старом macOS пути `/Volumes/PD1000/job/flutter/bin/flutter`.

После применения сети нужны: Flutter pub get, dart format, flutter analyze, flutter test, сборка, снимки всех 11 экранов на коротком/высоком viewport и увеличенном тексте. Прежние Flutter smoke/golden тесты ожидают старые тексты и навигацию; их нужно согласовать с новой реализацией и регенерировать goldens по проверенным снимкам. Не считать мобильную часть готовой до этих проверок.

Нужна дальнейшая визуальная сверка с исходниками: фон, шрифтовые метрики, отступы, декоративные края входа и вертикальная композиция длинных экранов. Экраны без новых макетов сохраняют прежние сценарии в новой палитре.
